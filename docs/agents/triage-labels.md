# Triage Labels

工程技能使用五种规范角色。下表将规范角色映射到本仓库本地 issue tracker 使用的状态词汇。

| Skill role        | Tracker status    | Meaning                       |
| ----------------- | ----------------- | ----------------------------- |
| `needs-triage`    | `needs-triage`    | 等待维护者评估                |
| `needs-info`      | `needs-info`      | 等待补充信息                  |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 agent 独立实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施                  |
| `wontfix`         | `wontfix`         | 不会实施                      |

技能提及规范角色时，使用上表对应的 tracker 状态。
