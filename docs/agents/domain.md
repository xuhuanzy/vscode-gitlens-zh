# Domain Docs

工程技能探索代码库前，应按以下规则读取领域文档。

## Before exploring

- 优先读取仓库根目录的 `CONTEXT.md`。
- 若根目录存在 `CONTEXT-MAP.md`，则按其中映射读取与任务相关的上下文文档。
- 读取 `docs/adr/` 中与当前工作相关的架构决策。
- 文件不存在时正常继续，不应仅为满足目录结构而提前创建；领域建模流程会在术语或决策实际确定时按需生成。

## Layout

本仓库采用单上下文布局：

```text
/
├── CONTEXT.md
├── docs/adr/
└── i18n/
```

## Vocabulary

issue 标题、重构方案、测试名称与实现描述应使用 `CONTEXT.md` 定义的领域术语。若现有术语不足，应记录领域建模缺口，而不是自行引入含义重叠的同义词。

## ADR conflicts

若新方案与现有 ADR 冲突，必须明确指出冲突及重新评估该决策的理由，不得静默覆盖。
